# Синергия — восстановить связь

Учебная игра по теме «Синергия между социальными институтами».

**Играть:** https://caypoh23.github.io/synergy-game/

Семь миссий: два профессиональных кейса, диаграмма Венна, INSERT, ФСМУ, кластер и финальный тест. Доступны самостоятельный и командный режимы, обучение на примере, сохранение прогресса и экспорт ответов.

## Запуск

Откройте `docs/index.html` в браузере или запустите:

```sh
python3 -m http.server 4178 --directory docs
```

Затем откройте http://localhost:4178 . Файл содержит шрифты, иллюстрации, стили и JavaScript; отдельная установка зависимостей для игры не нужна.

Прогресс хранится в браузере на текущем устройстве. Между локальным файлом, опубликованным сайтом и другими устройствами он автоматически не переносится.

## Публикация

GitHub Pages публикует папку `docs` из ветки `main`. Обновление `docs/index.html` и push в `main` запускают повторную публикацию. Проверка пакета: `python3 tools/verify.py`.

Актуальный файл — `docs/index.html`. Не изменяйте образовательное содержание, иллюстрации или сохранённый формат прогресса при обычном обновлении публикации. Перед новым релизом проверьте игру на широком и узком экранах, обучение, выбор и исправление ответа, следующий шаг и перезагрузку.

Встроенные уведомления о лицензиях Golos Text и Lucide находятся в HTML. Иллюстрации подготовлены для этой игры; лицензия сторонних шрифтов или иконок не распространяется автоматически на всю игру.
